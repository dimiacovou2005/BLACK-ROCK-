# Agenda App — CN6008

## Run the app

1. Import `backend/schema.sql` in phpMyAdmin (XAMPP).
2. Copy `backend/*` to `C:\xampp\htdocs\agenda-api\`.
3. Start Apache + MySQL.
4. `npm install` then `npm run web`
5. Login: `maria@example.com` / `demo123`
